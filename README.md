# ICA redesign prototype v0.5

Extract the ZIP and open `index.html` in a browser. You can also run
`python3 -m http.server 8000` from the extracted folder and visit
http://localhost:8000/. All prototype pages and assets work offline.

Start at Home, try each of the four shortcuts, then open a news report.
At phone widths, use the Menu button to reach the main navigation.
Search filters the prototype’s small index of pages and reports.

The files are ordinary HTML, CSS and JavaScript. Styles and shared behaviour
are in `assets/style.css` and `assets/site.js`.

See DESIGN-DECISIONS.md for source material, design decisions and open items.
